IMBLEO WEBSITE

ready-to-host/
The complete static website. Upload the CONTENTS of this folder to your web host.
Includes the homepage, a Services page, 11 case-study detail pages, a searchable
work index, and the Business Anatomy scroll story at /business-anatomy/.

editable-source/
The source project. No npm package installation is required.
From this folder, run:
  npm run build
  npm run check
  npm run dev
Then open http://localhost:4173.
After building, copy editable-source/dist/ over ready-to-host/ to update it.

Do not open ready-to-host/index.html directly through file://.
The site uses module scripts and root-relative routes, so use an HTTP server.

The contact flow prepares an email draft addressed to talktous@imbleo.com.
No enquiry is sent automatically.
Update the address in editable-source/scripts/build.mjs and
editable-source/public/assets/app.js when the company inbox is ready.

Case studies are labelled as the team's prior experience. Each case page states
whether the work was delivered, partly delivered, a design or a prototype, and
metric notes are retained. Status labels are not shown as badges.
Mock interfaces are clearly illustrative and use fictional sample data.

The homepage does not mention Zoho (npm run check enforces this).
The logos under the hero are placeholders until real logos are approved.
The original logo file is editable-source/public/assets/logo.jpeg.
